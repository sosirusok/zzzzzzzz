# 진격의 좀비 EPISODE 1 — 브라우저 플레이어블

GitHub Pages에서 별도 설치 없이 실행되는 HTML/CSS/JavaScript 액션 게임입니다. 제공된 자료를 바탕으로 비리부트판 Episode 1의 대기실, 네 가지 직업, Stage 0~4 진행 구조를 구현했습니다.

## 실행

정적 파일 서버의 루트에 이 디렉터리를 두면 됩니다. 로컬에서는 다음처럼 실행할 수 있습니다.

```powershell
python -m http.server 8080
```

이후 `http://localhost:8080`을 엽니다.

## 조작

- `WASD` 또는 방향키: 이동
- 마우스 왼쪽 버튼 또는 `Space`: 직업 기본 공격
- `Esc`: 일시 정지
- 터치 기기: 화면 하단 방향 패드와 공격 버튼

## 구현 범위

- `입장하기` 화면과 4인 대기실
- 아처, 메딕, 체어맨, 파이어맨 선택 및 자료에서 확인된 공격 수치
- Stage 0 출발 구역, Stage 1 운동장, Stage 2 카페테리아, Stage 3 교실동, Stage 4 교장실
- 웨이브, 시설 파괴, 열쇠 회수, 출구, 보스 제한시간, 증원 로직
- 공급된 직업·좀비·시설 PNG를 잘라 사용하는 캔버스 렌더링
- PeerJS 기반 방 코드, 참가자 목록, 직업 선택, 방장 시작 동기화
- 네트워크가 차단되거나 PeerJS를 불러오지 못해도 로컬 플레이 가능

## 멀티플레이 범위

현재 P2P 동기화는 대기실 참가, 닉네임/직업, 방장 권한, 게임 시작까지입니다. 전투 중 위치·적·피해 상태는 아직 각 브라우저에서 로컬로 계산되므로 완전한 실시간 협동 동기화는 아닙니다.

## 정확도 안내

직업 공격 수치와 문서에서 명시된 목표·시간은 제공 자료를 우선해 적용했습니다. 자료에 없는 맵의 픽셀 좌표, 일부 적 체력·속도·출현 좌표는 플레이 가능하도록 추정값을 사용했습니다. 따라서 원작과 100% 동일하다고 표방하지 않습니다.

이름 있는 인간/학생 캐릭터는 프로젝트에서 의도적으로 제외했습니다. 에셋 범위는 `ASSET-NOTICE.md`를 참고하세요.

## 파일 구성

- `index.html`: 입장 화면, 대기실, 게임 HUD
- `styles.css`: 반응형 화면과 컨트롤
- `data.js`: 직업, 적, Stage 0~4 데이터
- `assets.js`: 공급 이미지에서 허용된 영역을 로드하는 스프라이트 매니페스트
- `network.js`: PeerJS 방/대기실 동기화
- `game.js`: 입력, 전투, AI, 목표, 스테이지 진행, 렌더링
