# 진격의 좀비 EPISODE 1 — 클래식 브라우저 재현

GitHub Pages에서 실행되는 HTML/CSS/JavaScript 플레이어블입니다. 2024 리메이크·리부트가 아닌 구형 Episode 1 영상과 제공 자료를 기준으로 대기실부터 Stage 0~4까지 순서대로 진행합니다.

## 조작

- `WASD` 또는 방향키: 이동
- `J`: 대기실 석궁 발사 / 게임 공격
- 터치 기기: 화면 방향 패드와 `J` 버튼

대기실에서 석궁으로 네 직업 표적을 맞혀 아처·메딕·체어맨·파이어맨을 선택합니다. 최초 입장자(방장)만 시작할 수 있고, 3→2→1 카운트다운 뒤 항상 Stage 0부터 시작합니다.

## 구현된 원작 규칙

- 플레이어 숫자 HP 없음: 좀비 접촉 시 즉시 `부상`
- 메딕의 3초 접촉 치료와 자가 치료
- 시간 반복 웨이브가 아닌 위치별 1회 `진격` 트리거
- Stage 2 제조 시설 HP 200 및 파괴 필수
- Stage 3 일곱 후보 중 무작위 열쇠와 출구 조건
- Stage 4 제한 185초, 교장 선생님 HP 1250
- 아처 1×7 관통, 메딕 1×5 첫 적중·1초 스턴, 체어맨 3×2, 파이어맨 3×3 연속 분사
- 방 코드 기반 최대 4인 P2P, 방장 권한, 입력·전투 상태 스냅샷 동기화

## 정확도 경계

직업·적·시설 수치와 확인 가능한 진행 규칙은 제공 문서 및 구형 플레이 영상에 맞췄습니다. 원본 데이터 파일로 확인할 수 없는 전체 타일맵 좌표, 일부 고정 스폰 좌표, Stage 0~3 제한시간, Stage 4 캐비닛 증원 간격은 영상 기반 복원/추정입니다. 따라서 해당 부분까지 원본과 100% 동일하다고 표방하지 않습니다.

맵 배경과 런타임 스프라이트는 제공 화면·영상에서 분리한 실제 픽셀 자료이며, AI 생성 대체 이미지는 사용하지 않습니다. 세부 출처와 처리 내역은 `assets/runtime/provenance.json`과 `ASSET-NOTICE.md`에 기록합니다.

## 로컬 실행

```powershell
python -m http.server 8080
```

이후 `http://localhost:8080`을 엽니다.

## 파일 구성

- `index.html`: 입장 화면, 대기실, 클래식 HUD
- `styles.css`: 16:9 반응형 화면과 터치 컨트롤
- `data.js`: 직업, 적, Stage 0~4 데이터
- `assets.js`: 실제 런타임 에셋 매니페스트와 프레임 애니메이션
- `network.js`: 최대 4인 방, 방장 시작, 입력·스냅샷 동기화
- `game.js`: 타일 단위 공격, 부상/치료, AI, 진격, 목표, 순차 진행
