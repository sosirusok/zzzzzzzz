# PROJECT HUNTERS — 클래식 브루드워 스타일 팬 메이드 RTS

브라우저에서 실행되는 **클래식 실시간 전략(RTS) 게임**입니다. 1998년식 정통 RTS의
플레이 감각(하단 콘솔 UI, 포그 오브 워, 12유닛 부대 지정, 공격 지정/홀드/순찰,
락스텝 멀티플레이)을 재현했으며, **3개 종족 전체**와 테크트리·마법·특수능력을 구현했습니다.

> **비공식 팬 프로젝트 고지**
> 이 프로젝트는 블리자드 엔터테인먼트와 무관한 비상업 팬 제작물입니다.
> 원작의 그래픽·사운드·데이터 파일은 **일절 포함하지 않으며**, 모든 그래픽은
> 코드로 그린 프로시저럴 오리지널 아트, 모든 사운드는 WebAudio 신디사이저로
> 실시간 합성한 자체 제작물입니다. 게임 수치(체력/공격력/비용/시간 등)는
> 공개 위키(Liquipedia)에 문서화된 게임 데이터를 참조했습니다.

## 실행 방법

정적 파일만으로 동작합니다. 저장소 루트에서:

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

GitHub Pages로 호스팅해도 그대로 동작합니다 (멀티플레이는 HTTPS 권장).

## 게임 모드

- **싱글 플레이어** — 컴퓨터(쉬움/보통/어려움) 상대 최대 8인 슬롯 자유 편성, 팀전 지원
- **멀티플레이어** — 서버 없는 WebRTC P2P 락스텝 동기화. 1대1부터 다인전(최대 8인,
  사람+컴퓨터 혼합)까지. 호스트가 만든 초대 코드 ↔ 게스트 응답 코드를
  메신저로 교환하면 연결됩니다 (STUN만 사용, 별도 서버 불필요)

## 맵 — 헌팅 그라운드 (128×128, 8인)

중앙 개활지를 둘러싸고 **12시·1시 반·3시·4시 반·6시·7시 반·9시·10시 반**
8개 스타팅 포지션이 시계 방향으로 배치된 클래식 8인 레이아웃.
각 본진은 고지대 플래토 + 경사로, 미네랄 8덩이(1500) + 가스 간헐천(5000).

## 구현된 시스템

**종족/유닛** — 테란 13종, 저그 16종, 프로토스 16종 유닛 + 종족별 전체 건물 트리
(애드온, 저그 건물 변태(레어/하이브/성큰/스포어/거대 둥지탑), 프로토스 파일런 전력망, 크립 확산)

**전투 판정** — 피해 타입(일반/폭발/진동) × 유닛 크기(소/중/대) 배율,
장갑 선차감(원작 순서), 플라즈마 보호막 별도 판정, 최소 피해 0.5,
멀티히트 무기(질럿 8×2·발키리 6×8·파이어뱃 8×3), 뮤탈 글레이브 3연쇄(1/3 감쇠),
러커 직선 스플래시, 시즈탱크/리버/지뢰 방사 스플래시, 언덕 아래→위 공격 빗나감

**경제** — 왕복 8미네랄/8가스, 고갈 간헐천 2가스, 사령부/해처리/넥서스 자원 반납,
SCV 수리(비용 차감), 저그 재생, 보호막 재생, 실드 배터리

**마법/특수능력** — 스팀팩, 시즈 모드, 은폐(고스트/레이스, 에너지 소모율 원작 값),
잠복, 스파이더 마인, 컴샛 스캔, 디펜시브 매트릭스, EMP, 이레디에이트, 야마토포, 락다운, 핵공격,
패러사이트, 인스네어, 브루들링, 다크 스웜, 컨슘, 플레이그,
사이오닉 스톰, 환상, 아콘/다크아콘 합체, 피드백, 마엘스트롬, 마인드 컨트롤,
리콜, 스테이시스, 디스럽션 웹, 메딕 힐, 캐리어 인터셉터, 리버 스캐럽, 수송선/벙커 탑승

**업그레이드/연구** — 공방업 3단계(종족·계열별 비용/증가량 원작 일치), 이속/사거리/시야/에너지
업그레이드 전체 (아드레날린, 발업, 싱귤래리티, 카론 부스터, U-238 등)

**UI** — 클래식 콘솔 레이아웃(미니맵/선택 패널/애니메이션 초상화/3×3 커맨드 카드),
종족별 콘솔 테마, 부대 지정(Ctrl+숫자, 최대 12유닛), 시프트 예약 명령, 어택땅(A)/홀드(H)/순찰(P),
드래그 선택, 더블클릭 동종 선택, 랠리 포인트(미네랄 랠리 시 자동 채취), 건설 고스트,
경보(공격/핵) 미니맵 핑, 채팅(Enter), 커스텀 커서, 체력/보호막/에너지 바

**AI** — 종족별 빌드오더, 확장, 가스 배분, 업그레이드, 병력 조합, 공격 웨이브,
방어 반응, 전차 자동 시즈. 3단계 난이도

## 원작과 다른 점 (v1 한계)

- 건물 띄우기(테란 리프트오프), 여왕 사령부 감염, 나이더스 커널 이동, 리플레이/저장은 미구현
- 경로 탐색·유닛 밀치기는 근사 구현이라 원작의 무빙 감각과 완전히 같지는 않음
- 스타팅 일꾼 채취 효율이 원작 수치와 약간 다를 수 있음
- 멀티플레이 참가자는 게임 시작 전에 모두 연결되어 있어야 함 (중도 참가 불가)

## 기술 구조

| 파일 | 역할 |
|---|---|
| `js/data.js` | 전 유닛/건물/업그레이드/마법 수치 (Liquipedia 검증) |
| `js/map.js` | 헌팅 그라운드 맵 생성 + A* 길찾기 |
| `js/engine.js` | 결정적 시뮬레이션 (24틱/초, 고정소수점) — 락스텝 동기화 대응 |
| `js/graphics.js` | 프로시저럴 스프라이트/지형/이펙트/미니맵/초상화 렌더러 |
| `js/ui.js` | 인게임 HUD·입력 |
| `js/ai.js` | 컴퓨터 플레이어 |
| `js/net.js` | 로컬/WebRTC 락스텝 드라이버 (250ms 턴, 2턴 입력 지연, 해시 동기화 검증) |
| `js/audio.js` | WebAudio 신디사이저 SFX |
| `js/main.js` | 메뉴/로비/게임 루프 |

의존성 0, 빌드 과정 0 — 바닐라 JS + Canvas 2D.
